# Offline speech and phonics

## Current workflow (v1.13 and later)

All bundled narration and whole-word clips use complete independent ElevenLabs Roger responses. The publisher rejects batch-cut narration and fragment assembly. Reviewed phonics/name/blend recordings are maintained separately; do not overwrite them when updating ordinary narration.

The sections below this workflow describe the project's historical audio implementations and earlier releases. The Kokoro/eSpeak commands are not the current default and can replace mappings if run.

The current narration workflow uses local ignored generation plans and receipts in `.elevenlabs-cache/`:

```powershell
node scripts/repair-roger-boundaries.mjs --plan-only
# Review the pending utterance/character count before spending credits.
node scripts/repair-roger-boundaries.mjs
node scripts/publish-roger-library.mjs
```

Generation uses the project key from `.elevenlabs-cache/api-key.txt` or `ELEVENLABS_API_KEY`. Never commit the key or include it in an APK. The repair command resumes successful recordings from receipts; it does not purchase credits or adjust account/key limits. Whole-source publishing adds only trailing silence and records source hashes/durations. It requires the ignored source files and plans, so a fresh clone needs those development inputs restored before regeneration.

With the preview server and browser dependencies available, validate with:

```powershell
npm test
node scripts/test-roger-library.mjs
node scripts/test-elevenlabs.mjs
```

Source-dependent checks require the local receipts/masters. Local ASR audit tools also require the separately installed Python audio dependencies/model and their audit job files. Automated decoding, routing and transcript checks do not establish every pronunciation's naturalness; retain parent-reviewed source choices.

## Historical implementation and release notes

`speech.js` provides `SpeechService.say`, `letter`, `phoneme`, `word`, and `stop`. Speech emits `speech-state` events for the robot’s mouth animation. Calls cancel preceding playback and resolve when playback completes or is canceled.

## Narration and alphabet names

Normal narration and full-word audio use MonsterRescue’s local Kokoro preparation tools. Alphabet names use an explicit dictionary in `scripts/letter-pronunciation.mjs`, including the name inside sentences such as “A is for ant.” Custom words without a sentence recording use the dedicated letter-name clip followed by the remaining phrase. Android speech handles unrecorded text.

## Phonics

The original isolated neural phoneme clips proved unreliable despite passing playback tests. Current phonics use eSpeak NG in English-US real-word context. The preparation tool reads its phoneme timing events, extracts only the requested sound, using native synthesis timing (80 wpm, with reviewed word contexts for clearer stop releases). There is no post-processing time stretch; phoneme clips always play at rate 1. The speech engine is a development dependency; the phone receives only audio recordings.

`audio/phonics-reference.json` records each sample’s keyword, target IPA, actual selected phoneme events, source boundaries, and all 106 word comparisons. “Zebra” uses z / iː / b / ɹ / ə, including a separate schwa token. Kitten’s teaching pronunciation retains t + schwa + n while the reference engine uses a US glottal/syllabic-n variant.

Brief sound segments target about 0.46 seconds and sustained segments about 0.68 seconds before playback speed adjustment. Sounds are not replaced by alphabet names or deliberately repeated. These formant-generated clips sound different from the narration. Phoneme selection checks establish what the engine was instructed to produce and what segment was extracted; human listening remains necessary to judge clarity and teaching quality.

## Checks

Beginning/end blend cues are generated by `node scripts/generate-blend-audio.mjs` from the isolated reference consonant WAV bank, rather than cutting the target word. Continuous consonants retain their onset, exclude the final 40 percent of the reference keyword sample from sustain processing, and hold the steady sound for 0.48 seconds with a clean fade; stops retain their natural release. Components are joined with a 5 ms crossfade, without a vowel, repetition, playback-rate change, or time stretching. The phone uses `blend:<word-id>:<letters>` recordings; new custom blends use sequential held phonemes. `sustain-phoneme.mjs` shares the sustain helper with Letter Sounds. `prepare-speech.mjs` also includes all ordered built-in rhyme pairs and the vowel-name introduction.

Letter Sounds has a separate sustained clip bank. After regenerating reference phonics, run `node scripts/generate-held-phonics.mjs`. This holds the steady middle without slowing playback or changing sample spacing. For the 12 continuous consonants, only the first 60 percent of the reference source is available to the sustain algorithm, excluding the word-boundary tail; the held consonant fades to silence over 25 ms. Vowel/diphthong endings remain intact. Stops/glides retain their short articulation. Sound It Out continues to use the native reference bank. The held bank is indexed under `phoneme-held:` and described by `audio/phonics-held.json`.

- `node scripts/test-phonics-reference.mjs`: all word sequences and selected phoneme identities, including zebra.
- `node scripts/test-letter-pronunciation.mjs --published`: all alphabet-name sentence mappings.
- `node scripts/test-speech.mjs`: playback routing, cancellation, fallback, mute, and audio coverage.
- `node scripts/test-playback.mjs`: actual browser playback and decoding, with `npm start` running and Playwright installed.

A successful file/decode test alone does not establish correct pronunciation. Review the app with the intended learner as well.

Sound It Out uses its own `phoneme-clear:` bank when a word ID is supplied. Regenerate with `node scripts/generate-clear-phonics.mjs`; metadata is in `audio/phonics-clear.json`. Continuous consonants and simple vowels exclude the final 40 percent of their source and sustain for 0.5 seconds with a clean fade. Stops use native word-initial releases. Word-specific insect sounds take precedence; regenerate with `node scripts/generate-insect-sounds.mjs`. Both automatic sound sequences and sound-chip replay use this routing.

## Human recording overrides

`node scripts/publish-human-phonics.mjs` publishes e, ee, i and f from source files in `.human-phonics-cache`. Source URLs/hashes and edits are in `audio/human-phonics.json`; credits and CC BY-SA 3.0 terms are bundled. The script never loops or stretches these recordings. `phoneme-natural:` takes precedence over generated/held sounds, after word-specific overrides; `letter-natural:e` gives the E alphabet name its own human /i/ take. Existing generated banks remain available as fallbacks. Keep `phonics-credits.html` and the credit file with the APK; grown-up settings links to the full 52-sound review page. Re-run publication after intentionally regenerating source banks if needed; general narration generation preserves valid indexed overrides.

After publishing/replacing any `phoneme-natural:` consonant, run `node scripts/generate-blend-audio.mjs`. Preassembled blend recordings now prefer those natural components without looping/stretching and publish adaptation credits. `test-manual-content.mjs` rejects blend metadata that still points to a synthetic component when a human override exists.

# Speech boundary repair (v1.11.1)

The first compositional migration generated unpunctuated words and fragments as consecutive inputs in one dialogue. Those inputs coarticulated: `is for` followed `gift`, so timestamp cuts could carry a neighboring consonant into a shared fragment. Parent heard "dis for" across Learn Letters. Local ASR reproduced the old A example as "A does four and". Decoding/text-assembly tests did not detect the audible error.

`repair-roger-boundaries.mjs` independently generates all 171 unpunctuated pieces (one utterance per HTTP response, no timestamp cuts), plus all 132 Learn Letters introductions/example sentences as whole recordings. The publisher uses complete responses for these pieces and bypasses composition for those 132 sentences. Names use readable name spellings where appropriate, but A stays literal `A`: an initial `Ay` candidate was transcribed as I and replaced before release. Revised A/ant, A/ape and B/bat examples matched their intended phrases in local transcription checks; this is supporting evidence, not a naturalness certification.

Run the repair before `publish-roger-library.mjs`. Completed identical jobs are reused; changing spokenText invalidates only that recording. The publisher requires every repair receipt before committing the new index. The library test now requires whole independent recordings for every Learn Letters introduction/example, preventing regression to a name + shared is-for assembly. Other complete punctuated source sentences retain their previous recordings.
